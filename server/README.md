# راه‌اندازی پراکسی امن برای «مشاوره هوش مصنوعی»

بخش «دامپزشک هوش مصنوعی» اپ برای تحلیل مشکلات گیاه از Claude (مدل‌های Anthropic)
استفاده می‌کند. برای این کار به یک کلید API نیاز دارید — ولی این کلید **هرگز
نباید داخل کد اپ اندروید قرار بگیرد**، چون هر فایل APK یک بسته عمومی است و
هرکسی که آن را دریافت کند می‌تواند هر رشته‌ای که داخل کد پایتون نوشته شده
باشد (از جمله یک کلید API) را استخراج کند. اگر این اتفاق بیفتد، هرکسی
می‌تواند با کلید شما درخواست بفرستد و هزینه‌اش از حساب شما کسر شود.

راه‌حل: یک واسطه‌ی کوچک و رایگان (Cloudflare Worker) بین اپ و Anthropic قرار
می‌گیرد. کلید فقط روی این واسطه (سمت سرور) ذخیره می‌شود؛ اپ فقط با آدرس
واسطه حرف می‌زند و هیچ‌وقت خودِ کلید را نمی‌بیند.

```
[اپ اندروید] --(بدون کلید)--> [Cloudflare Worker] --(با کلید، سمت سرور)--> [Anthropic API]
```

## مراحل (حدود ۵ دقیقه، کاملاً رایگان)

1. یک کلید API از **https://console.anthropic.com** بسازید (بخش API Keys).
2. یک حساب رایگان در **https://dash.cloudflare.com** بسازید (نیاز به کارت
   بانکی ندارد).
3. از منوی سمت چپ: **Workers & Pages → Create → Create Worker**. یک اسم
   بدهید (مثلاً `plant-vet-proxy`) و روی Deploy بزنید (فعلاً با کد پیش‌فرض).
4. روی Worker ساخته‌شده کلیک کنید → **Edit code**. کل کد پیش‌فرض را پاک کنید
   و محتوای فایل `cloudflare-worker.js` (همین پوشه) را جای آن بگذارید →
   **Deploy**.
5. برگردید به صفحه‌ی Worker → **Settings → Variables and Secrets → Add**:
   - نام: `ANTHROPIC_API_KEY`  |  مقدار: کلید واقعی از مرحله ۱  |  نوع: **Secret**
   - (اختیاری ولی پیشنهادی) نام: `APP_SHARED_SECRET`  |  مقدار: یک رشته
     دلخواه و طولانی (مثلاً یک UUID) | نوع: **Secret**
     این کار باعث می‌شود فقط اپ خودتان بتواند از این Worker استفاده کند، نه
     هرکسی که آدرس آن را حدس بزند یا پیدا کند.
6. بالای صفحه‌ی Worker، آدرس آن را کپی کنید (چیزی شبیه
   `https://plant-vet-proxy.your-name.workers.dev`).
7. فایل `screens/ai_vet_screen.py` را باز کنید و در ابتدای فایل:
   ```python
   PROXY_URL = "https://plant-vet-proxy.your-name.workers.dev"
   APP_SHARED_SECRET = ""  # اگر مرحله ۵ (بخش اختیاری) را انجام دادید، همان رشته را اینجا بگذارید
   ```
8. تغییرات را کامیت و push کنید تا نسخه بعدی APK با تنظیمات درست ساخته شود.

## تست سریع (اختیاری، بدون نیاز به اپ)

از ترمینال:
```bash
curl -X POST https://plant-vet-proxy.your-name.workers.dev \
  -H "Content-Type: application/json" \
  -d '{"model":"claude-sonnet-5","max_tokens":100,"messages":[{"role":"user","content":"سلام"}]}'
```
اگر یک پاسخ JSON از Claude برگشت، پراکسی درست کار می‌کند.

## نکات

- **رایگان بودن**: پلن رایگان Cloudflare Workers روزانه ۱۰۰,۰۰۰ درخواست
  می‌دهد که برای یک اپ شخصی/هابی کاملاً کافی است.
- **محدودیت مصرف بیشتر (اختیاری)**: در داشبورد Cloudflare، بخش
  **Security → WAF → Rate limiting rules** می‌توانید بدون نوشتن کد یک
  محدودیت مثل «حداکثر ۲۰ درخواست در دقیقه از هر IP» هم اضافه کنید تا از
  سوءمصرف جلوگیری شود.
- **هزینه Anthropic**: این پراکسی فقط مسیر ارتباط را امن می‌کند؛ مصرف واقعی
  API همچنان طبق قیمت‌گذاری Anthropic از حساب شما کسر می‌شود. برای محدود
  کردن هزینه، در **https://console.anthropic.com** بخش Billing می‌توانید
  سقف مصرف ماهانه تعیین کنید.
- اگر ترجیح می‌دهید به‌جای Cloudflare Workers از سرویس دیگری (مثلاً Vercel
  یا یک سرور شخصی) استفاده کنید، فقط کافی است همان منطق `cloudflare-worker.js`
  (دریافت درخواست از اپ → افزودن کلید → فوروارد به Anthropic → برگرداندن
  پاسخ) را در آن پلتفرم پیاده کنید؛ کد `ai_vet_screen.py` تغییری نیاز ندارد،
  فقط کافی‌ست `PROXY_URL` را به آدرس جدید تغییر دهید.
